# CinéLibre

**Projet indépendant fondé par Lauris Coucaud.**

CinéLibre est un portail de découverte de films, séries, documentaires et chaînes proposés gratuitement et légalement par leurs diffuseurs. La disponibilité varie selon les territoires. Les liens renvoient vers les plateformes officielles ; aucune copie non autorisée n'est hébergée ici.

## Publication gratuite avec GitHub Pages

1. Ouvrir **Settings** dans le dépôt GitHub.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/(root)**, puis enregistrer.
5. GitHub affichera l'adresse publique une fois la publication terminée.

Le site est un fichier statique `index.html` : aucun serveur ni abonnement de constructeur n'est nécessaire pour cette première version.
